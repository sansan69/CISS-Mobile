Modern Component Rules
  • Cards: 20px radius, 1px border, subtle shadow, 16px padding
  • Hero panels: gradient background using primary/primarySoft, rounded 24px bottom corners
  • Metric cards: horizontal scroll on mobile, soft tinted backgrounds, no borders
  • Buttons: fully rounded (pill) for primary, rounded 12px for secondary
  • Lists: card rows with leading avatar/icon, title, subtitle, trailing status chip
  • Inputs: outlined style, 12px radius, filled surface background
  • Motion: page transitions 200ms, list stagger 50ms, FAB scale on press
